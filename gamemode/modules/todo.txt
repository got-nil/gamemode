/*

for all modules, a MODULE const is defined.
The id is the directory name for the module.
{
   name (string) = Pretty name
   description (string) = A brief description
   author (string) = The author(s) of the module
}

Once a module is loaded, call hook 'GNIL.core.ModuleLoaded' with the
returned MODULE table before it is re-inserted/cached into the list
of all modules. (Essentially allowing modification of modules from hook)

Module directory structure:
    sh_...   - Shared file
    cl_...   - Client file
    sv_...   - Server file
    
    (sv_)init.lua    - If the init file has no prefix or sv_, it is loaded serverside only.
    sh_init.lua      - If the init file is shared it is loaded on both the server and client.
    cl_init.lua      - If the init file is client then it can only include already loaded modules from the server.

    *INIT FILES ARE LOADED IN THE ABOVE ORDER (SERVER, SHARED, CLIENT) ONCE THE
     FIRST IS FOUND IN THE LOAD ORDER IT STOPS TRYING TO FIND OTHER INIT FILES.
     ANY INIT FILE IS EXCLUDED FROM AUTOLOADING.

     ONLY ONE INIT FILE PER MODULE OR IT WILL GET MAD AT YOU.

When a module is loaded, ONLY THE BASE DIRECTORY FILES ARE LOADED. Any
nested file MUST BE INCLUDED SEPERATELY BY THE MODULE.

*/

// not really required, but we should have it for preformance reasons
local MODULE = MODULE

MODULE.name = "Funny Module"
MODULE.description = "This module does absolutely hilarious shit im sure"
MODULE.author = "morgverd & virtualraptor"

// The id (directory name) of another module that is required before
// this one should continue loading.
// TODO: ENSURE THERE IS LOOP PROTECTION!
MODULE:Require("module_id")

// This allows module specific logging for debugging purposes.
// Just shows the module name in any logs for caller clarification.
MODULE:log(...) // -> Alias of GNIL.log(...) with module name tag included.

// This is an alias to GNIL.Utils.Hooks.Add, however it associates the
// module with the hook created. This means that for module unloads any
// associated hooks can automatically be removed

// If the 2nd argument is a string it is treated as the ID that should
// be used when creating the hook. This can ONLY be removed using 
// the same MODULE:RemoveHook(hookname, id)

// Real ID: gnil.modules.<module_name>.think.whatever
MODULE:AddHook("Think", "whatever", function()
    print("this is efficient code")
end)

// Remove a module specific hook that was created with an identifier. If an
// identifier was not provided above, an int/string (number) can be provided
// to remove the hook added based on its order.
MODULE:RemoveHook("Think", "whatever")

// Hook/Callback functions that are called when the given module is changed.
// You could also just hook into the actual hooks, but you'd also have to
// validate that the hook being unloaded is the current one. This is just a
// shortcut basically.
MODULE:OnLoad()         // -> GNIL.core.ModuleLoaded
MODULE:OnUnload()       // -> GNIL.core.ModuleUnloaded
